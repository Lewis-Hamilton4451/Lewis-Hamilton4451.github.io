过滤了 ' " or | - \ / * < > ^ ! ~ x hex ( ) + select ，所以`~~1000`也用不了了，因为过滤了hex十六进制想到可以使用二进制`0b1111101000`，MySQL中`0b`是二进制字面量

`0b1111101000 = 512 + 256 + 128 + 64 + 32 + 8 = 1000`

payload : id=`0b1111101000`

还有一种payload: id=`500 div 0.5`，`div`在MySQL中相当于除法

由web1-web7可知：

* 对于一个参数（例如题中的`id=1000`），可以用很多种表达方式，**转换成运算表达式（加减乘除，位运算），二进制，十六进制**，可以用来绕过一些简单的过滤
  
* `preg_match`在php中是匹配函数
